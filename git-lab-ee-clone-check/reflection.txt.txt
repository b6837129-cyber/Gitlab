ในการทำงานพัฒนาโปรเจกต์ครั้งนี้ ผมได้นำ AI เข้ามาเป็นผู้ช่วยในการบริหารจัดการระบบ Git Control ในทุกขั้นตอนของการทำงาน
เริ่มตั้งแต่การใช้ AI ช่วยตรวจสอบสถานะปัจจุบันของ Git (git status) เพื่อติดตามดูว่ามีไฟล์ใดที่ถูกแก้ไขไปแล้วบ้าง
พร้อมทั้งใช้ AI วิเคราะห์ดูประวัติการเปลี่ยนแปลงย้อนหลัง (git log) เพื่อทบทวนรายละเอียดและลำดับการพัฒนาของโค้ด
จากนั้นผมได้ใช้ AI ตรวจสอบความถูกต้องของสาขา (Branch) การเชื่อมต่อไปยัง Remote Repository และช่วยดูไฟล์ที่ยังไม่ถูกติดตาม (Untracked Files)
รวมถึงวิเคราะห์ตรวจสอบโครงสร้างโฟลเดอร์ทั้งหมดให้อยู่ในรูปแบบที่ถูกต้องและเป็นระเบียบเรียบร้อย
เมื่อเจอข้อผิดพลาดเชิงเทคนิคอย่างปัญหา .git ซ้อนกัน ผมก็ใช้ AI ช่วยหาแนวทางแก้ไขและจัดการลบส่วนซ้ำซ้อนออกได้อย่างปลอดภัย
หลังจากนั้นผมจึงใช้ AI ช่วยตรวจสอบความเรียบร้อยก่อนทำการเพิ่มไฟล์เข้าสู่ระบบ Git (git add) เพื่อเตรียมพร้อมสำหรับการ Commit
ปิดท้ายด้วยการใช้ AI ช่วยทดสอบและรันโปรแกรมให้แน่ใจว่าระบบทำงานได้อย่างถูกต้อง สมบูรณ์ และไม่มีข้อผิดพลาดก่อนส่งงานขึ้น GitHub
