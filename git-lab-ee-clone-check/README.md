# DC Circuit Calculator

## ชื่อโครงงาน

DC Circuit Calculator

## คำอธิบาย

แอปพลิเคชันคำนวณทางไฟฟ้าสำหรับวิเคราะห์วงจรไฟฟ้ากระแสตรง (DC) ช่วยให้ผู้ใช้สามารถคำนวณค่ากระแสไฟฟ้าและกำลังไฟฟ้าของวงจรตัวต้านทานได้อย่างรวดเร็วและแม่นยำ พร้อมแสดงขั้นตอนการคำนวณที่เข้าใจง่าย

## วัตถุประสงค์

เพื่อคำนวณหากระแส (Current) และกำลังไฟฟ้า (Power) ในวงจรตัวต้านทานตามกฎของโอห์มได้อย่างสะดวกและถูกต้อง

ใช้สำหรับเรียนแลปคอมโปรไฟฟ้า
